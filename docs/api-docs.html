cropy (1.0.0)

Download OpenAPI specification:

AI 기반 농작물 병해충 진단 및 스마트 방제 지원 API.

사용 순서

  1. /api/v1/capabilities에서 지원 작물·업로드 한도·기능을 확인합니다.
  2. /api/v1/ready로 실제 모델의 추론 준비 상태를 확인합니다. /health는 생존 확인입니다.
  3. /api/v1/diagnose에 JPEG/PNG 사진을 multipart로 전송합니다.
  4. 재촬영 안내가 있으면 /api/v1/diagnose/{diagnosis_id}/refine을 사용합니다.
  5. HTTP 200이어도 save_status=failed이면 recovery_token으로 결과 저장을 재시도합니다.

공통 규칙

  • 현재 애플리케이션에는 인증·사용자별 이력 분리 기능이 없습니다.
  • 진단 출처는 prediction_mode로 확인합니다. 개발용 mock 결과는 실제 모델 추론이 아닙니다.
  • 처리된 HTTP 오류·입력 검증 오류·DB 오류·사진 저장 오류는 detail, code, retryable, request_id를 반환합니다. 단, /ready의 503은 준비 상태 객체입니다. 응답의 X-Request-ID로 요청을 추적합니다. 처리되지 않은 서버 예외의 500 응답은 일반 텍스트일 수 있으며 공통 JSON 형식을 보장하지 않습니다.
  • 사진 파일 파트에는 image/jpeg 또는 image/png Content-Type을 사용합니다. 서버는 image/* MIME과 실제 JPEG/PNG 파일 내용을 모두 확인합니다. 전체 요청 본문 한도는 upload.max_bytes + 65536바이트이며, /api/v1/offline/records는 upload.max_bytes * 2 + 65536바이트입니다.
  • Idempotency-Key는 진단·재촬영 요청에서 선택 사항입니다. 같은 키로 동일 요청을 재전송하면 보관된 결과를 재사용하며, 다른 사진/작물을 보내면 409입니다.
  • /uploads/{filename}은 응답의 이미지 URL을 제공하는 정적 경로입니다. GET/HEAD로 JPEG/PNG를 제공하며 업무 API 목록에는 포함되지 않습니다.
  • Swagger의 Try it out은 실제 서버를 호출하므로 진단 및 저장 요청은 기록을 생성할 수 있습니다.

브라우저에서 생성한 예측값과 사진을 저장합니다. 서버 모델 재추론은 수행하지 않으며 prediction_mode=browser입니다. metadata는 JSON 객체를 문자열로 직렬화한 multipart 폼 필드입니다. predictions는 클래스 0~8을 각각 포함한 9개 확률이고 합계는 1±0.001이어야 합니다. created_at은 시간대가 필요하고 2000년 이후·서버 현재 시각+5분 이하여야 합니다. 버전들은 해당 묶음 manifest와 일치해야 합니다. 재촬영 시 refined_predictions와 refined_file을 함께 보내세요. client_record_id로 중복을 판별하며 동일 ID에 다른 내용을 보내면 409입니다. HTTP 200의 save_status도 확인하세요.
